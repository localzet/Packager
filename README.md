# Localzet Packager

Проект упаковщика приложений Localzet Server и Triangle Framework в автономные исполняемые файлы на базе static-php-cli.

## Статус

Реализован CLI-прототип для Linux x86-64. Он проверяет manifest и Composer-граф, собирает PHAR, проверяет фактическую версию PHP и расширения из `micro.sfx`, затем объединяет их через закреплённую версию static-php-cli. 4 ноября 2026 текущий Server 7 был собран Packager и проверен в контейнере `scratch` без системных библиотек: HTTP, TLS, два worker-процесса и штатное завершение по SIGINT прошли. Подробности и SHA-256 приведены в [отчёте о совместимости](docs/compatibility-spike.md) и [его русской версии](docs/compatibility-spike.ru.md).

## Принятая архитектура

- CLI принимает проект, lockfile Composer, entrypoint, target и явный список PHP extensions.
- Изолированный build worker вызывает закреплённую версию static-php-cli 2.x; интерфейс backend отделён для будущего перехода на стабильный major.
- Сборка создаёт бинарник, manifest с SHA-256 и SPDX 2.3 SBOM по production `composer.lock`; отдельные команды создают Ed25519 подпись и проверяют её по доверенному публичному ключу.
- Планируется онлайн-проверка лицензии; после последней успешной проверки приложение сможет работать офлайн до 7 дней. Клиент, API и lease пока не реализованы.

Подробные C4 представления, ADR, этапы и критерии готовности: [архитектура](docs/architecture.md).

## Ограничения безопасности

Micro SAPI объединяет интерпретатор и PHAR, но не компилирует и не шифрует исходники PHP. Обфускация может повысить стоимость анализа, но не гарантирует секретность. Лицензионная проверка ограничивает запуск и отзыв, но может быть изменена при достаточной мотивации. Не включайте в бинарник секреты приложения или ключи подписи lease.

## Статус реализации

Packager пока не готов к широкому использованию: на x86-64 прошёл smoke в `scratch`, включая TLS с временным самоподписанным сертификатом; production-сертификаты, ARM64, воспроизводимость сборок и независимая проверка артефактов ещё не проверены. Онлайн-активация и дистрибутивы для пользователей не реализованы. SBOM формируется из lockfile и содержит `NOASSERTION` там, где нет подтверждённых сведений о лицензиях. Сборка требует заранее установленный production vendor graph и runtime `micro.sfx`. Начните с [инструкции CLI](docs/cli.md); полный compatibility gate остаётся открытым.
