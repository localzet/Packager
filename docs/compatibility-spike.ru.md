# Проверка совместимости: Server 7 и Localzet Packager

## Предыдущая проверка static-php-cli

- static-php-cli `2.8.6`, PHP `8.4.27`, Linux x86-64.
- `micro.sfx` собран из исходников с расширениями `zlib`, `phar`, `posix`, `pcntl`, `sockets`, `openssl`, `ctype`.
- Самостоятельный бинарник Server 7 обработал HTTP-запросы двумя workers и штатно завершился по SIGINT.

## Повторная проверка Packager — 04.11.2026

Packager собрал текущий Server из commit `e82db87e618e4582d2904479edcf7d8a91714451`. Сборка прошла на временной копии проекта с установленными только production-зависимостями Composer, static-php-cli `2.8.6` и тем же `micro.sfx`.

Полученный бинарник запущен под непривилегированным UID в Docker-образе `scratch`: корневая файловая система только для чтения, `/tmp` смонтирован отдельно. В образе не было системного PHP и динамических библиотек; исполняемый файл статически связан.

| Артефакт | Значение |
| --- | --- |
| SHA-256 бинарника | `62201339c8811e6b5f52e9a5bf1fa7597797fb104eeab4c54f24c78260b52167` |
| SHA-256 metadata | `3a4d3704738395a995d8bd0633fb5ee745962fa9bd521a3a66552fb7cfdc29d7` |
| SHA-256 SPDX SBOM | `b9665bbff9252d5995f99c023123e57f75669bb1728a581d7fa1a4a26d6daae5` |

Проверено:

- 20 HTTP-запросов получили успешные ответы от двух разных worker PID.
- HTTPS-запрос с временным самоподписанным сертификатом вернул HTTP 200.
- SIGINT завершил процесс с кодом 0.
- Комплект «бинарник + metadata + SBOM» подписан и проверен командами Packager с временной парой Ed25519; права закрытого ключа — `0600`.

Проверка подписи тем же CLI подтверждает его рабочий путь, но не заменяет независимый verifier и процедуру управления production-ключом. Контейнер использовал host networking, потому что fixture привязывается к loopback. Исходящие сетевые соединения не проверялись.

## Что ещё не подтверждено

- ARM64-сборка и запуск.
- Загрузка production-сертификатов и работа за reverse proxy.
- TCP/UDP-протоколы для конкретного упакованного приложения.
- Воспроизводимость результата на независимых сборочных узлах.
- Независимая проверка подписанного артефакта и provenance attestations.
- Семантическая проверка SPDX сверх проверки JSON Schema.
- Клиент и сервер онлайн-активации, отзыв lease и офлайн-режим до семи дней.

Эти smoke-проверки не означают готовность Packager к production-релизу. Полные ограничения и критерии выпуска описаны в [архитектуре](architecture.md#delivery-stages-and-readiness); [англоязычный отчёт](compatibility-spike.md) содержит те же технические результаты.
